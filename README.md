# zoul-factory

## 地狱全图 · 自殁至投胎

一张可交互的三维「地狱竖井」图：从一个人阳寿尽处起，到重入胞胎为止，把民间冥界体系的每一站画在一处。

打开 `index.html` 即可，无需构建、无外部依赖（无 CDN、无字体外链、无框架）。

### 图中所绘

竖井自上而下：阳世 → 阴阳界 → 殁 → 勾魂 → 黄泉路 → 鬼门关 → 孽镜台（一殿初审）→
十殿逐审（十层）→ 十八狱（收束成漏斗）→ 忘川·奈何桥 → 醧忘台·孟婆汤 → 井底的六道轮回盘。

一魂只跨越阴阳界两次：殁时下行，投胎时上行。故此图是一个闭环 —— 六道之中无一处是终点。

图下另有图说：阳间做七与阴间过殿的时序对照、十殿名号司职、十八狱罪因与刑期、
不在正路上的「别所」（枉死城、血污池、望乡台、酆都）、四桥分渡、六道详解。

### 操作

| 动作 | 效果 |
| --- | --- |
| 拖动 | 绕井旋转（左右改方位，上下改俯角 18°–82°） |
| 滚轮 | 沿井升降；到顶或到底则交还页面滚动 |
| 方向键 | 上下升降，左右旋转（需先点中场面） |
| 点名牌 | 飞至该层，并高亮下方对应图说 |
| 右侧导轨 | 跳至十站中任一站 |
| 随魂下行 | 自阳世自动巡游至轮回盘，约二十秒 |

### 实现

- 纯 CSS 3D 变换建的场面：环层为 `rotateX(90deg)` 的水平圆环，镜头由 `--camY / --yaw / --pitch` 三个自定义属性驱动。
- 名牌是真实 DOM，每帧施加镜头旋转的逆变换（`rotateY(-yaw) rotateX(-pitch)`）令其永远正对镜头 —— 故汉字在三维中仍然清晰可选。
- 远近以每帧计算的透明度作雾，非 `filter: blur`，七十余个元素仍可六十帧。
- 明暗双主题：暗色为阴司（烟墨、朱砂、铜），亮色为阳世麻纸（墨、朱批）。跟随系统，也响应查看器的主题切换。
- 尊重 `prefers-reduced-motion`：关闭飘尘与自动巡游，旋转与升降仍可用。
- 竖排汉字用「宽一字 + 强制换行」实现，不依赖字体的纵向度量（`writing-mode: vertical-rl` 遇缺纵向度量的字体会叠字）。

### 体系来源

民间流传的佛道混合冥界体系，非任何一家教义的定本。十殿名号、王姓、诞辰与所主地狱主要依《玉历宝钞》一系的十王信仰；
地狱名相、六道与中阴四十九日之说出自佛典；城隍、无常、判官等职司则是阳间官府制度整套搬入阴间的结果。
各地异说甚多（十八狱次第、奈何桥数目、枉死城归属等），遇分歧则从《玉历宝钞》，页末尾注已列明。
