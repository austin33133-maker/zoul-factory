# 战斗手感规格（Combat Feel Spec）

> 这份文档的用途：让程序不用猜。所有数值都是**初始实现值**，上线前必须经过盲测调优，但开工时必须有一个具体数字。
> 单位：距离 m，时间 s / ms，帧按 60fps 计（1 帧 = 16.6ms）。

---

## 1. 延迟预算（最高优先级）

从物理按键按下到屏幕上出现变化，总预算 **≤ 50ms**。分配：

| 环节 | 预算 | 说明 |
|---|---|---|
| 输入采样 | ≤ 16ms | 每帧采样，不做输入平滑，不做死区外的额外滤波 |
| 逻辑处理 | ≤ 16ms | 开火判定在 Update 中立即执行 |
| 渲染出图 | ≤ 16ms | 关闭 VSync 时不做多帧排队（Max Queued Frames = 1） |

**硬规则：**
- 开火判定发生在**按下的那一帧**，不等开火动画、不等枪口特效、不等音效加载。
- 视角输入不做任何平滑/加速（除非玩家在设置里主动开）。鼠标平滑是手感杀手。
- 动画只是表现层，永远不能反过来阻塞逻辑（no animation-driven gameplay）。

---

## 2. 移动

| 参数 | 值 |
|---|---|
| 基础移动速度 | 5.2 m/s |
| 冲刺速度 | 7.8 m/s |
| 加速度 / 减速度 | 60 / 45 m/s² |
| 空中控制 | 地面的 35% |
| 跳跃高度 | 1.1 m（起跳 0.42s 滞空） |
| 滑铲 | 初速 9.5 m/s，持续 0.6s，末段可跳取消 |
| 翻越（vault） | ≤ 1.3m 障碍自动翻越，耗时 0.35s |
| 默认 FOV | 100（可调 80–120，开镜 FOV 独立） |

**摄像机**：跑动 headbob 幅度 ≤ 0.8°（宁可不足，不可过量）；落地下沉 0.06m / 恢复 0.12s；转向不做惯性拖尾。

---

## 3. 开火与命中判定

- **判定方式**：突击步枪/冲锋枪/霰弹/左轮 = hitscan；狙击 = hitscan + 穿透；榴弹/钉枪/电弧 = projectile。
  理由：hitscan 反馈最直接，projectile 只用在"弹道本身是玩法"的枪上。
- **首发精度**：静止且未移动 0.15s 后，第一发 100% 命中准星中心。这是"第一枪必中"契约，破坏它玩家会觉得游戏在骗人。
- **爆头倍率**：×2.0（狙击 ×3.0）。爆头必须有独立音效和独立 hitmarker 形状——不能只是数字变大。
- **弹道可视化**：每 3 发一条曳光，玩家自己的曳光轻微偏离枪口指向以避免遮挡准星。

### 后座模式

```
前 4 发：100% 确定性 pattern（可被玩家背下来并压枪）
5–8 发：pattern + 15% 随机水平偏移
9 发以后：pattern + 35% 随机
停火 0.25s 后：视角以 0.18s 平滑回落到开火前位置（回复 90%，剩 10% 保留惩罚）
```

设计意图：**奖励练习，但不惩罚新手到绝望。** 纯随机后座让技术无法积累，纯固定后座让老手无脑压枪。

---

## 4. 命中反馈：五通道，必须同帧

一次成功命中，以下 5 项在同一帧内全部触发。缺任何一项都算 bug，不算"优化项"。

| 通道 | 规格 |
|---|---|
| **视觉·准星** | hitmarker 显示 0.06s，普通/爆头/击杀三种形状，爆头额外一圈扩散 |
| **听觉·命中音** | 按目标材质分层：肉体（闷）/ 护甲（金属脆）/ 护盾（电子）/ 环境（尘）。命中音音量比开火音低 6dB，但频段错开保证可辨 |
| **目标·受击** | 闪白 0.05s（HDR 过曝，不是简单换色）+ 受击后仰 0.08s，位移 ≤ 0.15m |
| **弹着点** | 火花/碎屑粒子 + 贴花，方向沿法线反射 |
| **数字** | 伤害数字，从命中点向上飘 0.4s，爆头数字大 40% 且换色。**设置里可关**（硬核玩家会关，要尊重） |

### 击杀反馈（在命中反馈之上叠加）

- 低频 punch 音（80–120Hz，给"实感"）
- 击杀精英时：0.08s 的 20% 时间缩放（**仅精英与 Boss**，杂兵不做，否则清杂兵会卡顿感）
- 手柄震动：左马达 0.12s 短脉冲
- 屏幕边缘 0.1s 极轻微暗角脉冲（幅度 ≤ 5%，宁可玩家察觉不到）

**反面清单（明确不做）**：全屏抖动 > 0.5°、每次击杀都慢动作、命中时锁定视角、屏幕血迹遮挡。这些都是"以为在加爽感，实际在夺走控制权"。

## 5. 武器操作节奏

| 动作 | 耗时 | 备注 |
|---|---|---|
| 切枪 | 0.25s | 可在收枪阶段被开火打断（拔枪射击） |
| 换弹（普通） | 1.6–2.4s | **任意时刻可被冲刺/滑铲/切枪打断**，进度不保留 |
| 换弹（战术，弹匣未空） | 快 25% | 奖励主动管理弹药 |
| 开镜 | 0.18s | 开镜过程中即可开火，不强制等待 |
| 近战 | 0.4s，可取消 | 击中回 10 护盾，鼓励贴身 |

**慷慨原则**：这是 PvE。所有"惩罚性"设计（换弹锁死、切枪僵直、跑动后延迟恢复精度）一律放宽。玩家的挫败应该来自敌人，不来自操作系统。

---

## 6. TTK 目标区间

| 场景 | 目标 TTK | 说明 |
|---|---|---|
| 玩家 → 杂兵 | 0.25–0.4s | 保证"清杂兵"是爽的节奏动作，不是任务 |
| 玩家 → 精英 | 4–7s | 一个完整的走位循环 |
| 玩家 → Boss | 60–120s | 分 3 阶段，每阶段有节奏变化 |
| 杂兵 → 玩家（满血满盾） | ≈ 2.5s 持续承伤 | 有反应窗口，但站桩必死 |

**难度层 D1→D5 的调整方式（按优先级）：**
1. 敌人组合更刁钻（远程+近战夹击）
2. 出场节奏更密（波次间隔缩短）
3. 增加精英数量
4. 敌人行为参数（预警时间缩短、移速提高）
5. ——最后才是血量，且上限 +60%，绝不 ×3

血量膨胀直接稀释每一枪的反馈，是最廉价、最伤手感的难度手段。

## 7. 验收方法（怎么证明"手感做好了"）

不靠"我觉得挺爽"，靠可观测指标：

1. **白盒打靶测试**：全灰模、无音乐、只有靶子。招 10 个盲测者，记录**主动停止前的持续打靶时长**。中位数 ≥ 3 分钟才算过关。
2. **盲测口头反馈**：让测试者只用形容词描述每把枪。如果 8 把枪里有 3 把以上被描述为同一组词，说明武器差异化失败。
3. **延迟实测**：高速摄影（240fps）拍摄按键到屏幕变化，实测 ≤ 50ms。不接受"感觉挺快"。
4. **反馈剥离实验**：逐一关闭 5 个反馈通道，让测试者盲评爽感下降幅度。任何一个通道关掉后没人察觉，说明这个通道做得不够、需要重做而不是删掉。
