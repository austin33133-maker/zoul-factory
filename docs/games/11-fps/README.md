# 11 · FPS 射击游戏策划案（代号 Z-11 / 《OVERCLOCK》）

> 这不是一份"可选方案汇总"，而是一份带取舍的决策文档。每一节都写明"我选什么"和"为什么砍掉另一个"。
> 配套文档：[战斗手感规格](./combat-feel-spec.md) · [里程碑与验证](./milestones.md)

---

## 0. 一句话定位

**一款 25 分钟一局、单人为主的第一人称 Roguelite 射击游戏：用极致的开枪手感做地基，用每局重组的构筑（Build）做重复可玩性。**

参照坐标：《Gunfire Reborn》的构筑深度 × 《DOOM Eternal》的战斗节奏 × 《Ultrakill》的反馈密度，但体量只有它们的 1/5。

---

## 1. 第一个决策：先砍掉 PvP

大多数人说"做 FPS"时脑子里想的是 CS / 无畏契约。**我不做 PvP 竞技，一期直接砍掉。** 理由不是它不好玩，而是它对团队规模的要求是另一个数量级：

| PvP 竞技射击隐含的必需成本 | PvE Roguelite 是否需要 |
|---|---|
| 权威服务器 + 回滚/延迟补偿网络代码 | 否（单人；联机用 Host 权威即可） |
| 匹配系统 + 分段 + 赛季运营 | 否 |
| 反作弊（持续对抗，永无止境） | 否 |
| 首日必须有足够并发玩家，否则匹配空转 | 否，单人游戏第 1 天和第 1000 天体验一致 |
| 平衡性需长期驻场调优 | 局部平衡即可，玩家会用构筑自我解压 |
| 内容压力：地图必须对称、公平、耐玩 | 关卡可程序化拼接，允许不公平（那是难度） |

一句话：**PvP 的成本大头在"游戏之外"，PvE 的成本大头在"游戏之内"。** 小团队的钱应该全部花在能被玩家直接摸到的东西上——也就是"枪好不好打"。

同一个战斗内核，未来若要加 PvP 或 3 人合作，是加法；反过来从 PvP 退回 PvE，前面砸的钱全废。

---

## 2. 目标用户

- **核心（决定成败）**：玩过至少一款 Roguelite（吸血鬼幸存者 / 挺进地牢 / 枪火重生）的 PC 玩家，18–32 岁，单次游玩时长 40–90 分钟。
- **次核心**：射击手感党。会因为"这把枪听着爽"买单，会看 B 站/YouTube 的"手感测评"。
- **明确不服务**：追求叙事沉浸的 3A 玩家、要开黑社交的团队玩家、手游轻度用户。

用户判定标准（一句话）：**"死了之后，他会不会在 10 秒内点重开？"** 不会，就不是我们的用户，也不必迎合。

---

## 3. 三条体验支柱

所有需求都要能挂到下面三条之一。挂不上的，一律砍。

### 支柱 A：枪要"响"
命中的那一瞬间必须有多通道、同帧的反馈。这是第一优先级，比内容量、比美术、比剧情都高。
判定：把画面全部换成白盒灰模，玩家依然愿意连续打靶 3 分钟——这才算过关。

### 支柱 B：每一局都在赌
一局内做 12–15 次构筑选择，让玩家在 25 分钟里体验完整的"我很菜 → 我在成型 → 我是神"功率曲线。
判定：玩家能对别人复述"我这局是 XX 流"。说不出来，说明构筑没有辨识度。

### 支柱 C：空间即武器
关卡不是通道，是战斗场：有高低差、有可绕的柱、有断掉的路。玩家死的时候应该想"我站错位置了"，而不是"敌人血太厚"。
判定：同一房间同一波敌人，两个玩家的走位路线明显不同。

---

## 4. 核心循环

**秒级（0–3 秒）**：观察 → 选位 → 开火 → 命中反馈 → 微调
**局内（3–25 分钟）**：清房 → 掉落 → 三选一升级 → 变强 → 更难的房 → Boss
**局外（跨局）**：解锁武器蓝图 / 新的构筑零件 / 提升难度层 D1–D5

```
      ┌──────────────── 局外元进度（蓝图、难度层）────────────────┐
      │                                                          │
      ▼                                                          │
  选择武器 → [区域1: 4房] → 精英 → [区域2: 4房] → 精英 → [区域3] → BOSS → 结算
                 ↑    ↓                                              │
                 │ 三选一升级（每房 1 次，共 12–15 次）                │
                 └──────────────────────────────────────────────────┘
```

单局目标时长 **22–28 分钟**（中位数 25）。低于 15 分钟构筑来不及成型，高于 35 分钟失败惩罚过重、重开意愿断崖下跌。

## 5. 战斗设计要点

### 5.1 手感（详见 [combat-feel-spec.md](./combat-feel-spec.md)）

关键几条先摆这里，因为它们是整个项目的地基：

- 输入到画面延迟预算 **≤ 50 ms**（60fps 下 3 帧）
- 按下扳机 **第 0 帧就出伤害判定**，不等开火动画播完
- 命中反馈 **5 通道同时触发**：准星 hitmarker、材质化命中音、目标闪白、弹着火花、（可关的）伤害数字
- 换弹可打断（reload cancel）、切枪 0.25s、跑动不减精度惩罚过重——**对玩家慷慨**，这是 PvE 不是 PvP
- 后座前 4 发 100% 确定性（可背板），之后引入随机——奖励练习，但不让新手绝望

### 5.2 敌人：5 个原型，每个只教一件事

| 原型 | 教会玩家 | 关键参数 |
|---|---|---|
| 冲锋兵 | 不能站桩 | 高速、低血、成群 |
| 射手 | 要利用掩体 | 远程点射、有 0.8s 预警红光 |
| 盾兵 | 要换位/打弱点 | 正面免伤 90%，背后弱点 3 倍 |
| 自爆虫 | 要管理空间 | 逼玩家离开舒适位 |
| 精英/指挥官 | 要用构筑 | 分阶段、有召唤、有可打断读条 |

**原则：不靠数值堆叠造难度。** 提高难度层时，改的是"敌人组合与出场节奏"，不是把血量 ×3。血量膨胀是最廉价也最伤手感的做法——它让每一枪的反馈变弱，直接违反支柱 A。

### 5.3 玩家生存

- 血量 100 + 护盾 50（护盾 4 秒不受击后回复，血不自动回）
- 玩家被杂兵打死需要持续承伤 **≈ 2.5 秒** —— 有反应时间，但不能挨打
- 处决/近战击杀掉落少量护盾 → **鼓励进攻，惩罚缩壳**（这是节奏设计的核心开关）

## 6. 武器与构筑系统

### 6.1 武器：8 把，宁少勿滥

一期只做 8 把枪，但每把都必须有**唯一的机制标签**，而不是"伤害 32 / 射速 9 的另一把步枪"：

| # | 武器 | 唯一机制 |
|---|---|---|
| 1 | 突击步枪 | 基准枪，连续命中升温提升射速 |
| 2 | 霰弹枪 | 近距离击退，可用来自我位移 |
| 3 | 狙击枪 | 穿透 3 个目标，击杀回满弹 |
| 4 | 冲锋枪 | 命中叠"标记"，标记满自动引爆 |
| 5 | 榴弹发射器 | 弹跳抛物线，可延时引爆 |
| 6 | 钉枪 | 把敌人钉在墙上（控制） |
| 7 | 电弧枪 | 链式传导，越密集越强 |
| 8 | 左轮 | 单发高伤，爆头额外一发免费子弹 |

### 6.2 构筑三系

- **Mod（枪械改造）**：改弹道、弹匣、开火方式。例：三连发、弹跳弹、过热爆炸
- **Aug（身体强化）**：改移动与生存。例：滑铲无敌帧、击杀加速、二段跳
- **Anomaly（异常）**：高风险高收益，带明确代价。例：血量上限 -50%，伤害 +80%

**成型目标：4 条能被玩家说出名字的流派** —— 弹幕流 / 爆头流 / 引爆流 / 贴脸滑铲流。
一期不追求"无限组合"，追求"4 条路各自都爽，且能互相串味"。

### 6.3 一个关键规则

三选一升级里，**永远至少有一项与当前构筑强相关**（保证成型），**至少有一项无关**（保证意外）。纯随机会让玩家有一半的局"什么都没成"，那些局就是流失。

## 7. 关卡

- 手工白盒房间块 + 程序化拼接（Room Graph），**不做全程序化生成地形**——程序化地形在射击游戏里几乎必然产出难读的空间，违反支柱 C。
- 房间标准尺寸：小 18×18m / 中 28×28m / 大 40×40m + 2 层垂直
- 每个房间必须满足：至少 2 条进出路线、至少 1 处高台、掩体覆盖率 25–35%
- 一期房间数：**24 个手工房间**（3 主题 × 8），配合随机敌人组合 + 随机事件，感知重复度可接受
- 每区结尾必有一个"呼吸房"（无敌人、有商店/铁匠），控制情绪节奏

---

## 8. 表现层

- **美术风格：低多边形硬表面 + 强对比配色。** 理由是成本，也是可读性：敌人用高饱和描边色，环境去饱和，玩家永远能一眼分清"什么会打我"。写实风对小团队是陷阱。
- **音效优先级高于美术。** 射击游戏 70% 的爽感来自声音。每把枪要有：近景开火层、远景回声层、机械尾音层、命中反馈层，四层独立混音。
- UI 极简：准星、弹药、血条、构筑图标条。**不做小地图**（逼玩家看世界，不看角落）。

## 9. 技术方案

| 项 | 选择 | 理由 |
|---|---|---|
| 引擎 | Unity 6（URP） | 小团队迭代速度 > 画面上限；FPS Controller 自研不用 CharacterController |
| 网络 | 一期纯单机；M3 加 3 人合作（Host 权威 + 客户端预测） | 联机是加法，别在手感没做出来前碰它 |
| 目标配置 | 1080p / 60fps @ GTX 1060 | 覆盖 Steam 硬件调查主流区间 |
| 帧预算 | 16.6ms：渲染 8 / 逻辑+AI 4 / 物理 2 / 其他 2.6 | 敌人上限 40 同屏靠此倒推 |
| 平台 | Steam 抢先体验优先，手柄一等公民 | 主机移植留接口，不做一期目标 |

## 10. 商业模式

**买断制，一次性定价（EA 期 ¥58–68，正式版 ¥88）。** 不做内购、不做通行证、不做体力。

理由：目标用户是单人 Roguelite 玩家，这个群体对内购的容忍度极低，且我们没有运营团队。买断制让所有设计决策只需回答"好不好玩"，而不用回答"怎么让他明天再来"——这会显著提升设计效率。

后续变现靠 **DLC / 大型免费更新拉动第二波销量**，不靠榨取单个玩家。

写下来是为了以后有人提时可以直接指这一节：

## 12. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **手感做不出来** | 项目根基没了 | M0 就设死线：白盒打靶留不住人就重做或停项，绝不用美术掩盖 |
| 内容量不够，10 小时就腻 | 差评、退款 | 走"内容乘法"：24 房间 × 敌人组合 × 构筑，而非线性堆关卡 |
| 构筑失衡，出现唯一解 | 重复可玩性归零 | 每周跑一次全构筑自动模拟，胜率偏离阈值即调 |
| Roguelite 品类拥挤 | 曝光困难 | 差异点押在"手感"这一条，宣传素材全部围绕开枪的 3 秒切片 |
| 范围蔓延 | 延期、烂尾 | Cut List 写进合同/看板，任何新增必须先砍掉等量的旧需求 |

---

## 13. 如果只能记住三句话

1. **先砍 PvP**，把全部预算压在能被玩家直接摸到的手感上。
2. **手感是死线，不是优化项**：白盒阶段留不住人，后面所有内容都是沉没成本。
3. **不用数值膨胀造难度**，用敌人组合造难度——血条越厚，每一枪越不爽。
