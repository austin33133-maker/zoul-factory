# 🍊 橙子公主 Orange Princess

对标 Royal Match 的三消休闲游戏。原生 HTML5 + Canvas 2D，无第三方框架。

## 运行

直接打开 `index.html` 不行（ES Modules 需要 HTTP 协议）。任意 HTTP 服务都可以：

```bash
cd orange-princess
python3 -m http.server 8080
# 或
npx --yes serve .
```

然后浏览器访问 `http://localhost:8080/`。手机访问同 WiFi 的电脑 IP 也能玩。

## 已实现的玩法

### 对局
- **9×9 棋盘 + 6 种水果**：橙 / 草莓 / 柠檬 / 青苹果 / 蓝梅 / 葡萄
- **拖动交换** 相邻两颗水果（鼠标 + 触屏）
- **匹配检测**：3 连基础消除；4 连 → 🚀 火箭；L/T 形状 → 💣 炸弹；5 连 → 🌟 彩球
- **特殊棋子激活**：被消、被命中、或被交换出去都会触发
- **组合爆炸**：火箭+火箭 / 炸弹+炸弹 / 彩球+任意 / 各种交叉
- **重力下落 + 连击 cascade**：连击越高得分越高
- **障碍物 📦 木箱**：1 / 2 HP，相邻消除受伤；火箭/炸弹直接打碎
- **死局重排**：无可行交换自动重排
- **Combo 喊话**：连击逐级显示 Sweet!→Tasty!→Awesome!→Incredible!→Insane! 全屏大字 + 音效
- **火箭尾迹** / **彩球闪光**：明确的视觉反馈

### 关卡
- **3 星评分** + 4 种目标：收集色 / 得分 / 砸开木箱 / 多色钥匙
- **15 关**：橙园→木箱关→风暴塔→王座大厅，每关有 story 文案
- **战前选卡**：付费消耗金币购买 +5 步 / 起始火箭 / 起始炸弹

### 元玩法
- **🏪 商店**：充值金币（4 档礼包占位）+ 单买道具 / 生命
- **🏰 橙园别墅**：3 个房间（花园 / 大厅 / 厨房），各 5 件物品，用 ⭐ 星星解锁
- **生命系统**：5 颗心，30 分钟回 1 颗
- **金币系统**：通关 50 + 20×星数；步数差一点点可花 200 🪙 续 5 步
- **道具系统**：🔨 锤子（单点）/ 💣 炸弹（3×3）/ 🔀 交换
- **本地存档**：localStorage 持久化所有进度、星星、装修、道具

## 细节

- **橙子公主 mascot**：多层 Canvas 绘制（裙、皇冠、表情、眼神高光、腮红、呼吸动画）
- **5 种心情**：happy / cheer / worried / sad / wow，根据战况变化
- **气泡对话**：关键时刻公主会说话（"加油"、"差一点"、"哇"…）
- **粒子爆炸**：每次消除都有同色粒子飞溅
- **屏幕震动**：大爆炸有 shake
- **飘字得分**：combo 时显示倍率
- **音效合成**：Web Audio 实时合成，无音频文件
- **缓动动画**：sprite 插值，弹性下落

## 关卡

15 关，配置见 `src/game/levels.js`。第 11-15 关引入木箱机制和多色钥匙目标。

## 目录

```
orange-princess/
├── index.html               # 入口
├── styles.css               # DOM 层样式（模态、按钮、Toast）
└── src/
    ├── main.js              # 场景管理 + 输入 + 主循环
    ├── config.js            # 常量配置
    ├── storage.js           # localStorage 存档
    ├── audio.js             # Web Audio 合成音效
    ├── utils.js             # 通用工具
    ├── game/
    │   ├── board.js         # 棋盘 + 匹配 + 重力 + 特殊棋子规则（纯逻辑，可单测）
    │   ├── engine.js        # 游戏状态机：trySwap → cascade → win/lose
    │   └── levels.js        # 10 关定义
    ├── scenes/
    │   ├── map.js           # 关卡地图（蜿蜒小道 + 公主迎接 + 商店/装修入口）
    │   ├── game.js          # 对局场景（HUD + 棋盘 + 粒子 + 公主 + booster + Combo 喊话）
    │   ├── shop.js          # 商店：充值金币 + 道具单买
    │   └── decoration.js    # 橙园别墅：3 房间 / 15 件家具用星星解锁
    └── ui/
        ├── princess.js      # 橙子公主 Canvas 精绘
        └── modal.js         # DOM 模态
```

## 已知边界

- **未对标的部分**：装修系统、剧情过场动画、社交（好友救心）、广告、付费、活动；高级关卡机制（果冻、传送门、特殊地块）；丰富的动画细节（皇室仆从、城堡背景）
- **不会真实扣费**：所有付费/广告都是占位演示
- **资源最小化**：水果用 Emoji，公主纯 Canvas 绘制（保证零外部依赖）
- **未做服务器同步**：进度仅存本地

## 单元测试

```bash
node /tmp/test-engine.mjs    # 20/20 通过（含木箱、特殊棋子、组合爆炸）
```
