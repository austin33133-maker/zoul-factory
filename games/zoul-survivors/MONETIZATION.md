# 变现与留存设计

> 两个目标：**让玩家愿意一局接一局**，以及**在不破坏体验的前提下赚钱**。
> 这两件事在这个品类里不是矛盾的——恰恰相反，靠打扰赚的钱会同时干掉留存和收入。

---

## 一、留存设计：为什么会想"再来一局"

游戏结束到下一局开始，玩家的心理路径是固定的三步：
**「我差一点就赢了」→「我知道下次该怎么改」→「重开只要一下」**。
三步里断掉任何一步，这个玩家今天就不会再开第二局了。所以下面每一条都对着其中一步。

### 1. 第一次三选一必须在 8 秒内出现 ✅ 已实现

`xpForLevel()` 把前 5 级压得极低，实测**首次升级约 6 秒**。

新玩家在头 10 秒内还没形成"这游戏是干嘛的"的判断，必须先让他摸到一次「三选一」——那是这个品类的核心动词。等 30 秒才给第一次选择，一半的人已经退出去了。

### 2. 死亡到重开：1 次点击，0 加载 ✅ 已实现

结算页的「再来一局」直接调 `startRun()`，不过场动画、不回主菜单、不插广告。

**这个按钮的响应速度直接等于留存。** 行业里最常见的自杀操作就是在这里插一个 5 秒插屏广告——它能多赚一点点展示，代价是把最关键的冲动窗口按死。我们的插屏广告放在「回主菜单」那条路径上，不放在「再来一局」上。

### 3. 每一局失败都留下可见进度 ✅ 已实现

- 结算固定给金币（哪怕 10 秒就死）
- 商店里 8 项永久强化都有进度点阵，买完当场往前走一格
- 元进度上限刻意压低（最多 +50% 伤害、+120 生命）

**上限压低是故意的。** 元进度的作用是"让失败不白费"，不是"让你练级碾压"。一旦永久强化能替代技术和构筑，游戏立刻变成挂机，30 天留存直接归零。

### 4. 差一点就赢 ✅ 已实现

主菜单常驻「最佳存活 / 最高击杀」，每局结算都在和它比。近失败（差 10 秒破纪录）是重开意愿最强的时刻。

### 5. 每日首局金币翻倍 ✅ 已实现

`claimDaily()`。给"今天先开一局"一个具体的、当场兑现的理由。

刻意**没有做**签到日历 / 连续登录天数——那类设计制造的是"断签焦虑"，一旦断了反而成为弃坑理由。

### 6. 即时反馈密度 ✅ 已实现

连杀计数、清场道具、磁力吸取、精英击杀顿帧、屏幕震动、低血暗角。这些不是装饰——**Roguelite 的重复可玩性建立在"每一秒都有事情发生"上**，反馈稀疏的游戏玩三局就腻。

### 7. 构筑赌博 ✅ 已实现

三选一 + 4 张高风险异常卡（玻璃火炮 / 狂暴 / 超频 / 汲取）。玩家能对别人复述"我这局是玻璃火炮流"，这个可复述性就是重开的理由——他想再试一次别的流派。

---

### 明确不做的几件事

不是因为做不了，是因为**在这个品类里它们会亏钱**：

| 不做 | 原因 |
|---|---|
| 体力 / 心数 | 单人 Roguelite 玩家对"不让我玩"零容忍，直接推高卸载和差评 |
| 强制插屏才能继续 | 打断的正是重开冲动本身，省一步就多留一个人 |
| 连续登录断签惩罚 | 制造焦虑，断签后反而成为弃坑理由 |
| 付费直接买战力碾压 | 会让免费玩家和付费玩家同时失去玩的理由 |
| 抽卡 / 开箱 | 需要长期运营和合规成本，与"小团队买断+广告"的模型冲突 |

一句话：**靠"让玩家爽"留人，不靠"让玩家难受"留人。** 前者的收入天花板高得多，也不用天天应付退款和应用商店审核。

## 二、变现设计

模型：**混合休闲（Hybrid-casual）—— 激励视频为主，轻内购兜底。** 无强制广告。

### 三个激励视频位（已接好，见 `js/monetize.js`）

| 位置 | 触发点 | 每局限次 | 为什么是这里 |
|---|---|---|---|
| **复活** | 死亡界面，5 秒倒计时 | 1 | 转化率最高——玩家刚投入了 3 分钟，最不想归零。限 1 次是必要的：无限续命会毁掉难度，一旦难度没了，广告位本身也就没人点了 |
| **金币翻倍** | 结算页 | 1 | 零打扰、纯赠予，点击率通常最高 |
| **刷新三选一** | 升级面板 | 3 | 频次高，但必须限次。不限次会毁掉"构筑赌博"，而赌博感正是玩家重开的理由 |

设计原则：**三个位置全部是"看了变强"，没有一个是"不看不给玩"。**

### 插屏广告

只放在**回主菜单**这一条路径上，且每 3 分钟最多一次。永远不出现在「再来一局」上。

### 内购（占位已写好，待接平台）

| 商品 | 价格 | 作用 |
|---|---|---|
| 去广告 | ¥12 | **付费后所有激励奖励直接领取，不用看广告**——这是核心卖点。绝不能让付费玩家反而少拿东西 |
| 新手礼包 | ¥18 | 2000 金币 + 永久攻击 +10%，首日弹一次 |
| 金币包 | ¥6 / ¥30 | 加速元进度，不提供额外战力上限 |

关键约束：**内购只能买"时间"，不能买"上限"。** 所有永久强化免费玩家都能拿满，付费只是更快。这条守住了，评论区就不会出现"氪金游戏"。

## 三、收入测算（planning assumption，必须实测校准）

下面的数字是**行业量级的规划假设，不是实测值**。真实 eCPM 受地区、买量质量、广告平台竞价影响可以差 3 倍以上，上线后必须用真实数据替换。

**建模口径**（假设 50k DAU）：

| 项 | 假设值 | ARPDAU 贡献 |
|---|---|---|
| 激励视频 | 3.5 次/DAU × $12 eCPM | $0.042 |
| 插屏 | 3 次/DAU × $6 eCPM | $0.018 |
| 内购 | 转化率 2%，ARPPU $1.2/月 | ~$0.020 |
| **合计 ARPDAU** | | **≈ $0.08** |

50k DAU → 日流水约 **$4,000**。

**能不能赚钱只取决于一个不等式：LTV > CPI。**
按 D1 40% / D7 15% / D30 5% 的留存假设，LTV(180d) ≈ $0.9–1.4。这意味着买量 CPI 必须压在 $0.7 以下才有正毛利。做不到就只能靠自然量和达人内容，那对"第一眼是否好玩"的要求会高得多——所以前 10 秒的体验密度是商业问题，不只是设计问题。

**上线前必须实测校准的 4 个数**：真实 eCPM、激励视频人均观看次数、D1/D7 留存、CPI。

## 四、必须盯的指标

| 指标 | 目标 | 意义 |
|---|---|---|
| **死后 60 秒内重开率** | ≥ 55% | 这个品类的命脉。低了说明挫败感 > 期待感 |
| 首次三选一时间 | ≤ 8s | 新手漏斗最陡的一段 |
| D1 / D7 / D30 留存 | 40% / 15% / 5% | 混合休闲基准线 |
| 激励视频人均观看 | 3–5 次/DAU | 低了是广告位没设计好，高了要警惕体验被广告主导 |
| 单局时长中位数 | 3–5 min | 偏短说明难度失控，偏长说明节奏拖沓 |
| 构筑选取分布熵 | 无单项 > 35% | 超过说明存在唯一解，需要削 |
| 副武器使用率 | 无武器 < 5% | 低于 5% 的武器等于没做 |
| 退款 / 差评率 | < 5% | 超过通常意味着广告太吵或数值付费墙 |

## 五、上架前还缺什么

现在这个版本是**可玩的完整循环**，但离能上架还差这些（都是工程活，不涉及玩法）：

1. 应用图标、启动图、商店截图与预览视频
2. 隐私政策页 + GDPR 同意弹窗 + iOS ATT 授权弹窗（**不做会被拒审**）
3. 云存档（现在是纯 localStorage，换机/清缓存会丢档）
4. 崩溃与埋点上报（Sentry + 一套自定义事件）
5. 真实广告位 ID 与内购商品在平台后台配置
6. 多语言（当前仅中文，英文市场 eCPM 通常更高）
7. 音乐（现在只有合成音效，没有 BGM）
